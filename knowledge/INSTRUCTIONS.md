Diffusion Studio, a video editor, is running on this machine and you are connected to it.

Projects are folders of JSX; `open` a folder once, then write its files and save — the app recompiles and re-renders.

The tools are the whole API, and their descriptions are authoritative. The same tools exist as `dapi` commands for shells and scripts: `media_grab` is `dapi media grab`, a field like `perSheet` is `--per-sheet`, and the result is the same JSON either way. Each tool is documented once for both under `dapi://reference/tools/`.
