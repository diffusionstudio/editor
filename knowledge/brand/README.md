# Diffusion Studio brand

The fallback brand system: use it only when the brief, the project, or the user
supplies no branding of their own. Any branding they do specify wins.

When it applies, these references are the source of truth, and the bundled
library comes before anything newly made.

## Read the relevant references

| Task | Read |
| --- | --- |
| Visual design or graphics | `design.md` |
| Copy or writing | `voice.md` |
| Video | `design.md`, `video.md`, `library.md` |
| Assets, components, or compositions | `library.md` and the reference for its medium |

When work spans multiple rows, use each relevant reference.

## Apply the system

1. Check `library.md` before creating a brand asset, component, or composition.
2. Reuse the closest existing item and change its content or inputs.
3. Use relative paths to bundled assets instead of external file-share links.
4. Do not invent product facts, claims, assets, or brand rules.
5. Report missing inputs, deliberate exceptions, and reusable work that should join the library.
